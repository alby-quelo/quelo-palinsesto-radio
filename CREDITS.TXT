Software originale Quelo Palinsesto Radio
-----------------------------------------
  Quelo Palinsesto Radio | palinsesto radio automatico (griglia settimanale,
                           FILE / PLAYLIST / LIVE / LINK, ANTI BIANCO,
                           mixer Pulse, GUI PyQt + interfaccia web --web-only,
                           manuali PDF)
  Spin-off standalone dalla funzione palinsesto radio di Quelo Audiomaker
  (https://github.com/alby-quelo/Quelo-Audiomaker)
  La funzione ANTI BIANCO è anche l’origine concettuale di Quelo Anti Bianco
  (https://github.com/alby-quelo/quelo-anti-bianco)
