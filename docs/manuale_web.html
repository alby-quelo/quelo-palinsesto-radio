Manuale interfaccia WEB
versione “a prova di scimmia”

Cosa fa questo programma?

Mette in onda i file/playlist del palinsesto, riempie i buchi con l’ANTI BIANCO, e ti fa gestire tutto dal browser.

Dove lo apri?

Da un browser (sul computer della radio o da un altro PC in rete) vai a:

http://IP_DEL_COMPUTER_DOVE_È_INSTALLATO:8890/

Sostituisci IP_DEL_COMPUTER_DOVE_È_INSTALLATO con l’indirizzo IP della macchina dove gira Quelo (quello che vedi in Settimana, link giallo). Esempio: http://192.168.1.50:8890/.

Nota: 127.0.0.1 / localhost funzionano solo se apri il browser sulla stessa macchina. Da un altro PC non puoi usarli.

Questo PDF si apre dal pulsante Manuale PDF in alto a destra nella pagina web.

1 — La pagina intera (mappa)

Quando apri la pagina vedi questi blocchi, dall’alto in basso:

  1. Monitor (sinistra) + Settimana / rete (destra)
  2. Timeline (tutta la settimana)
  3. Inserimento Clip + Browser file
  4. MIXER + SETTING (più in basso: scorri la pagina)
Se non vedi MIXER o SETTING: scorri in basso con la rotella del mouse.

2 — MONITOR (partire / fermare / ascoltare)

  1. Guarda Stato: se è IN ONDA il motore sta girando.
  2. Start = avvia il palinsesto. Stop = ferma.
  3. Ascolta da browser = senti nel browser ciò che esce dagli altoparlanti della macchina.
  4. Il cursore Volume regola il volume dell’uscita del computer dove è installato; per regolare il volume sul tuo PC usa il volume del tuo PC.
ANTI BIANCO = quando non c’è una clip in onda, parte la playlist di emergenza (niente silenzio in antenna).

3 — SETTIMANA e rete

  1. Con ◀ ▶ o Oggi cambi la settimana mostrata in Timeline.
  2. Bind e Porta = su quale interfaccia e porta risponde la pagina web. Il link giallo sotto mostra l’indirizzo da aprire (http://IP_DEL_COMPUTER_DOVE_È_INSTALLATO:porta/).
  3. Se cambi Bind/Porta: premi Applica rete, poi riapri il link giallo (o digita il nuovo indirizzo nel browser).
Da un altro PC usa sempre l’IP della macchina Quelo, non 127.0.0.1. Porta e firewall: vedi le istruzioni di installazione / README.

4 — TIMELINE (vedere e gestire le clip)

  1. Ogni colonna è un giorno. Ogni riga è un’ora.
  2. I rettangoli colorati sono le trasmissioni programmate.
  3. Zoom: premi − o + vicino a “px/h” per rimpicciolire/ingrandire.
  4. Clicca una clip → si apre la finestra Trasmissione.

Nella finestra Trasmissione

  • Elimina = togli la clip dal palinsesto (chiede conferma).
  • Modifica = cambia orari / titolo / path.
  • Visualizza = dettagli.
  • Chiudi = chiudi senza fare niente.

5 — INSERIMENTO CLIP (mettere qualcosa in onda)

Hai tre modi veloci:

  1. In coda = mette la clip dopo l’ultima già presente nel database.
  2. Da adesso = parte da adesso.
  3. Inserimento manuale = tu digiti inizio (e fine se serve).

Passi per un FILE (il caso più comune)

  1. Scegli Tipo = FILE (o PLAYLIST / LIVE / LINK).
  2. Nel Browser file a destra vai nella cartella e clicca il file: il path si riempie da solo.
  3. Controlla Inizio e Titolo.
  4. Premi Aggiungi clip.
  5. Controlla che appaia sulla Timeline.
FILE e PLAYLIST durano quanto il file vero. LIVE e LINK di default durano 1 ora (puoi cambiare la Fine).

6 — CREA PLAYLIST (dai file già sul server)

  1. In Inserimento Clip premi Crea playlist.
  2. Scrivi un Nome playlist (es. Mattina).
  3. Scegli la Cartella di salvataggio (o Usa cartella del browser).
  4. Nel Browser file seleziona un brano e premi + ( − toglie l’ultimo).
  5. Quando la lista è ok: Salva → nasce un file .m3u.
Upload ≠ Crea playlist. Upload porta file dal tuo PC. Crea playlist usa file già sulla macchina.

7 — BROWSER FILE e UPLOAD

  1. Home / Su = navigazione cartelle.
  2. Scrivi un nome e Crea cartella per fare una categoria (es. Jingle).
  3. Upload apre la scelta:
  • File audio = carichi un brano (mp3, wav, …).
  • Playlist già pronta = carichi un .m3u già fatto + i file audio / cartella che cita.
  • Chiudi = annulla.

8 — MIXER

  1. Vedi gli ingressi (es. Microfono) con la barra VU.
  2. Il cursore Vol regola il volume di quell’ingresso.
  3. La spunta Mute silenzia quell’ingresso.
  4. Aggiorna rilegge la lista ingressi PulseAudio.

9 — SETTING (ANTI BIANCO e soglie)

  1. ANTI BIANCO playlist: clicca il campo o Sfoglia e scegli la playlist di emergenza (.m3u).
  2. Font clip e Zoom px/ora = solo aspetto della Timeline.
  3. Soglie intervento anti-bianco (FILE / LINK / LIVE):
    • Innesco (sec) = dopo quanti secondi di silenzio scatta l’anti-bianco.
    • Rilascio (sec) = quanto deve tornare il segnale prima di lasciare l’anti-bianco.
    • Soglia (dB) = sotto questo livello conta come “silenzio”.
  4. Alla fine: Salva setting.

10 — Ricetta veloce: mettere un brano in onda

  1. Apri la pagina web.
  2. Nel Browser file trova il file (o fai Upload).
  3. Premi Da adesso oppure In coda (dopo aver selezionato il file).
  4. Oppure: Inserimento manuale → compila → Aggiungi clip.
  5. Guarda la Timeline: deve comparire il rettangolo.
  6. Nel Monitor: se non è già in onda, premi Start.
  7. Opzionale: Ascolta da browser per verificare.
Se senti solo l’ANTI BIANCO: non c’è una clip che copre “adesso”. Controlla stato e Timeline sulla colonna di oggi.
